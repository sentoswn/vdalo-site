# Підключення кабінету й CRM (≈15 хвилин, один раз)

Поки нічого не підключено, сайт працює як раніше: заявки йдуть у Google-таблицю, а `/kabinet/` і `/crm/` показують демо (`?demo=1`).

## 1. Бот у Telegram (для входу)
1. Відкрийте @BotFather → `/newbot` → назва «Вдало», нік, наприклад `vdalo_robota_bot`.
2. Збережіть **токен** (рядок виду `123456:ABC...`).
3. Там само: `/setdomain` → оберіть бота → введіть `vdalo-robota.com.ua`.

## 2. Проєкт у Supabase (база даних)
1. Зареєструйтеся на https://supabase.com → **New project** (регіон — Frankfurt / eu-central-1). Запишіть пароль бази.
2. **SQL Editor** → New query → вставте весь файл `supabase/schema.sql` → **Run**.
3. **Project Settings → API**: скопіюйте **Project URL** і ключ **anon public**.
4. **Account → Access Tokens** → Generate new token (для автоматичного розгортання).

## 3. Секрети в GitHub
Репозиторій → Settings → Secrets and variables → Actions → New repository secret:

| Назва | Що вставити |
|---|---|
| `SUPABASE_ACCESS_TOKEN` | токен з кроку 2.4 |
| `SUPABASE_PROJECT_REF` | ID проєкту — частина адреси `https://<ID>.supabase.co` |
| `TELEGRAM_BOT_TOKEN` | токен бота з кроку 1.2 |
| `ADMIN_TG` | ваш нік у Telegram без @ (кілька — через кому) |
| `SUPABASE_DB_URL` | (необов’язково) Project Settings → Database → Connection string, URI — тоді схема оновлюватиметься сама |

Потім Actions → **Supabase** → Run workflow. Він розгорне функцію входу `tg-auth`.

## 4. config.json
У файлі `config.json` у корені репозиторію заповніть:
```json
{
  "supabaseUrl": "https://<ID>.supabase.co",
  "supabaseKey": "<anon public ключ>",
  "tgBot": "vdalo_robota_bot"
}
```
Ключ `anon` — публічний, його можна тримати на сайті: доступ до даних захищений правилами бази.

## 5. Перший вхід
1. Відкрийте https://vdalo-robota.com.ua/crm/ → «Увійти через Telegram». Ви — адмін (з `ADMIN_TG`).
2. **Налаштування** — шкала бонусу вже стоїть: 2 000 грн за першого друга в місяці, +200 за кожного наступного, до 4 000 грн. Змінити можна там же.
3. Менеджери: людина входить у `/kabinet/`, потім ви в CRM («Реферали й баланси») ставите їй роль «Менеджер».

## Як працює бонус
Кандидат приходить за посиланням `?ref=<код>` → заявка в CRM уже прив’язана до того, хто запросив (старі посилання з номером телефону теж розпізнаються, якщо людина вказала цей номер у кабінеті).
Коли менеджер ставить статус **«Відпрацював 2 тижні, оплату отримано»**, бонус автоматично з’являється на балансі запрошувача (лише один раз на заявку).
Запит на виплату приходить у вкладку «Виплати» → «Виплачено» списує суму з балансу.
